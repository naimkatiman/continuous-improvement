# Past Mistakes

Dated ledger of mistakes made in this repo and what now prevents each one. Referenced from [CLAUDE.md](../CLAUDE.md).

**Look here second.** The first lookup is the `recall` skill — it searches the observation log across every session and will surface a matching past failure without anyone having curated it. This file is the curated, durable subset: the mistakes worth stating as rules, each paired with the invariant that enforces it.

Roll entries older than 60 days into `docs/audits/archive-<quarter>.md`.

## Known environmental flake (not a regression)

`test/hook.test.mjs` — the observe.sh suite (`completes within 2000ms`, `exits 0 with valid tool call JSON`, `writes observation to JSONL file`, `writes project.json for new projects`) fails intermittently under the full parallel `npm test` run on a loaded Windows host, at 2.5–5.0s wall clock. It passes 15/15 when run in isolation. Do not inflate the timing budget to mask it.
